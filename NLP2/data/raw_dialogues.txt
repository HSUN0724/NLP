# 土味情話多輪對話語料（原始格式）
# 格式說明：
#   - 每段對話以「### 主題」開頭
#   - 「你：」是使用者，「專家：」是模型要學會的回答
#   - 每段至少 2 輪（你／專家各兩句以上）
#   - 以 # 開頭的行是註解，會被忽略
# 執行 python scripts/build_dataset.py 轉成 data/train.jsonl
